Parrotsay-c is a colorful cowsay clone featuring a parrot because they didn't add a parrot. It includes an interactive 24-bit true-color configuration system that lets you customize the beak, head, wings, and eyes. Your color choices automatically persist across runs by saving to a local JSON configuration file. You can easily pass messages directly via command-line arguments or pipe text straight into it from standard input. If you want to change your parrot's colors later, you can simply run the companion configuration tool. The repository also comes packaged with an Arch Linux PKGBUILD for quick and convenient installation. Feel free to fork, modify, and tinker with the script to suit your terminal aesthetic!
